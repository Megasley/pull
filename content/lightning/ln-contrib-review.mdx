Specification review keeps the network coherent. Practice evaluating proposals for clarity, edge cases, and backward compatibility.

Start with **Review Club** spec picks on this lesson, especially open PRs on [lightning/bolts](https://github.com/lightning/bolts/pulls).

## Review checklist

1. What problem does this solve?
2. How do existing nodes behave during rollout?
3. What new failure modes appear?
4. Are test vectors included?
