Landing a Lightning PR requires local labs (bitcoind + peers), patience with CI, and precise reproduction notes.

Use the **Review Club** picks from earlier chapters (visible on concept lessons) or find scoped work on [/issues](/issues). Tie your PR description to the protocol concept you fixed (liquidity, HTLC, routing, etc.).
