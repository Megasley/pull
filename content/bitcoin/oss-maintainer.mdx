Landing a meaningful PR is a communication skill. Expect iterations. Maintainers juggle scarcity of attention and high cost of mistakes.

## Collaboration loop

<Mermaid caption="Expect multiple rounds; keep commits and responses crisp." chart="sequenceDiagram
    participant You
    participant Maintainer
    You->>Maintainer: Open PR + tests
    Maintainer->>You: Review comments
    You->>You: Revise + explain
    You->>Maintainer: Push updates
    Maintainer->>You: ACK / request more" />

<Callout type="tip" title="Summarize each push">
