A Lightning POS is the canonical merchant integration: show amount → display invoice/QR → detect payment → mark order paid.

Key orders by ID and payment hash. Replaying webhooks must not double-fulfill. Prefer clarity and speed over ornamental UI - cashiers need huge type and an obvious paid state.
