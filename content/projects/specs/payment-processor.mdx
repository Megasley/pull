A payment processor turns "send bitcoin here" into an API merchants can integrate: create invoice → detect payment → confirm → notify.

### Suggested statuses

`unpaid` → `seen` → `confirmed` → `expired` / `underpaid` / `overpaid`

Only fulfill after proven settlement. Deliver webhooks with event IDs and allow merchants to safely retry.
